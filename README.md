# Car Price Prediction using Machine Learning

## Project Overview
This project uses Machine Learning to predict car prices based on available vehicle features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Model
Linear Regression is used to predict car prices.

## Project Workflow
1. Load and explore the dataset.
2. Handle missing values.
3. Prepare input features and target prices.
4. Split data into training and testing sets.
5. Train a Linear Regression model.
6. Evaluate performance using Mean Absolute Error (MAE) and R² score.
7. Compare actual and predicted prices.

## Model Evaluation
- **Mean Absolute Error (MAE):** 2102.36
- **R² Score:** 0.8643

These are the results obtained during this project run.

## How to Run
Open `Car_Price_Prediction.ipynb` in Google Colab or Jupyter Notebook and run the cells in order.
